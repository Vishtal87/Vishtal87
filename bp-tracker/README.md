# Дневник давления

Простой дневник измерений давления. Не медицинское изделие: не ставит диагнозов.

## Что есть
- давление, пульс, сахар, вес и приём лекарств: ввод с проверкой значений;
- категория по таблице AHA 2017 для давления; сахар и вес без категорий;
- история, графики, среднее за 7 дней;
- Pro по подписке: PDF-отчёт для врача, резервная копия, журнал приёма, синхронизация с Health Connect (Android);
- RU / EN;
- данные хранятся на телефоне, без регистрации, без рекламы и аналитики.

## Статус
| Часть | Статус |
|---|---|
| Логика, валидация, экспорт, Pro-гейтинг | готово, `npm test` (33 теста) |
| Экран приложения | готово, проверено на телефоне (базовый сценарий) |
| Health Connect, PDF, резервная копия, журнал приёма | собрано, на устройстве не проверено полностью |
| Покупка подписки и восстановление | не подключены (заглушки) |
| Напоминания, Apple Health | не реализованы |
| Публикация | см. `docs/store-listing.md` (блокеры перечислены там) |

Документы для магазинов: `docs/privacy-policy.md`, `docs/terms.md` (черновики, нужна проверка юристом).
