# Дневник давления

Простой дневник измерений давления. Не медицинское изделие: не ставит диагнозов.

## Что есть
- ввод верхнего, нижнего давления и пульса с проверкой значений;
- категория по таблице AHA 2017 для каждой записи;
- среднее за последние 7 дней;
- история, удаление записи долгим нажатием;
- экспорт в CSV (сейчас показывается текст; отправка файла — следующий шаг);
- данные хранятся на телефоне, без регистрации и облака.

## Статус
| Часть | Статус |
|---|---|
| Логика (категории, валидация, среднее, CSV) | готово, 6 тестов проходят |
| Экран приложения | готово, бандлы iOS и Android собираются (`expo export`) |
| Сборка APK / IPA в облаке (EAS) | нужен вход в аккаунт Expo: `npx eas build -p android` |
| Проверка на телефоне | не проверено |
| Отправка CSV файлом, напоминания, подписка | не начато |

## Запуск
```
npm test          # логика
npx expo start    # разработка, через Expo Go
```
