# tv-remote — ядро пульта

Рабочее название. Первая версия: управление телевизорами Roku и Samsung по локальной сети.

## Статус

| Часть | Статус |
|---|---|
| Единый набор кнопок | готово |
| Драйвер Roku (ECP, HTTP, порт 8060) | готово, тесты на подменённом HTTP |
| Драйвер Samsung (WebSocket, порт 8001, токен) | готово, тесты на подменённом WebSocket; **на реальном ТВ не проверен** |
| Поиск телевизоров в сети (SSDP / mDNS) | не начато |
| Интерфейс SwiftUI (iPhone) | не начато, нужен Mac с Xcode |
| Подписка через StoreKit 2 | не начато |
| Яндекс ТВ (STV-43FDUBK1R) | не поддерживается: протокол не подтверждён |

## Запуск тестов

```
npm test
```

Тесты не требуют телевизора: сеть и WebSocket подменены. Требуется Node 22 или новее.

## Структура

- `src/keys.mjs` — общие кнопки приложения и их коды для каждого бренда.
- `src/roku.mjs` — драйвер Roku.
- `src/samsung.mjs` — драйвер Samsung, сохраняет токен через `onToken`.
- `src/index.mjs` — `createDevice(brand, options)`. Новый бренд добавляется здесь отдельным модулем.
- `test/` — тесты протоколов.

## Что нужно проверить на реальном телевизоре

1. Roku: `POST /keypress/VolumeUp` меняет громкость, `GET /query/device-info` возвращает XML.
2. Samsung: первое подключение показывает запрос на экране, после подтверждения приходит токен, при повторном подключении запрос не появляется.
3. Samsung: в каких моделях работает порт 8001, а в каких нужен 8002 (wss).

## Не входит

- Яндекс ТВ, LG, Fire TV: в следующих версиях, после подтверждения протокола.
- Управление не через официальные приложения брендов: разбор чужих приложений не делаем.
